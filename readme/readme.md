A program backend fájljait az npm install paranccsal hoztam létre, ezért van a késői feltöltésük.
A  függőségek a package.json és package-lock.json fájlokban vannak.

A projekt célja a tárgyi kettes elérése, ugyanis az utolsó félév révén már a kapacitásomat nem erre koncentráltam (például a projekt alapötlete is kimondottan újrahasznált), hanem a kutatásomra, szakdolgozatomra, stb. Így a tárgyból csupán az átmenés és a záróvizsgára bocsátás a célom.
